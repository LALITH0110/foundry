# Evidence

Only sanitized evidence belongs here. A genuine discovery run stores its model decisions, UI observations, executed actions, and compiled artifact provenance under a run ID. Replay runs explicitly record `modelRequests: 0`.

The discovered artifact preserves the executed path from the linked Qwen run. Its provenance note records the later engineer-authored schema migration; no replacement model run is claimed.

The bootstrap artifact in `capabilities/prepare-stop-payment.example.json` is engineer-authored and is not represented as discovery evidence. Development runs live under `evidence/runtime/` and remain ignored. The selected runs under `evidence/reviewed/` were copied with `npm run curate:evidence` and scanned with `npm run check:evidence`.

Scenario evidence is generated by the deterministic test harness. Handoff cases use scripted operator callbacks so CI can verify ownership transfer, recorded human actions, and resume predicates; `npm run demo:handoff` is the separate manual path.

The reviewed set contains:

- genuine local-model discovery;
- successful model-free replay with different inputs;
- a `MEMBER_NOT_FOUND` business outcome;
- `ACCOUNT_NOT_FOUND`, restricted-account, and app-error outcomes;
- a pre-account session expiry that remains classified as `SESSION_EXPIRED`;
- an unexpected-state handoff with a recorded human action and validated resume;
- one automatic known-interstitial recovery and one failed-recovery escalation;
- a real `TIMEOUT` result with masked screenshot evidence;
- irreversible-step approval gating;
- a one-action policy budget that blocks the second action;
- a recovery run that exhausts the original budget after handoff;
- rejection of a corrupted final reason; and
- a blocked final-submit action.

Success and intervention snapshots contain semantic control inventories rather than unrestricted page text. Failure screenshots mask form fields and table values. Inputs, seeded names, cookies, storage, raw prompts, traces, video, HAR files, and unmasked screenshots are excluded.
